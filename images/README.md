# Картинки курсов

По умолчанию картинка курса — логотип школы (`logo-*.webp`) на карточке в цвет фона логотипа.
Логотипы обрезаны по краям надписи, чтобы на странице выглядеть одного размера.
Логотип и цвет фона задаются в `schools` в `src/courses.mjs`.

Чтобы поставить курсу свою картинку вместо логотипа:
- положите файл `kurs-N.webp` (N = место), 4:5, от 960×1200 px, главное в центре кадра;
- в `src/courses.mjs` замените у курса `image: null` на `image: 'images/kurs-N.webp'`;
- запустите `npm run build`.
