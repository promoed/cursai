# Картинки курсов

Положите сюда по одному файлу на курс: `kurs-1.webp` … `kurs-10.webp` (номер = место в рейтинге).

- Пропорции 4:5, от 960×1200 px. На мобильном картинка обрезается до 16:10 по центру, держите главное в середине кадра.
- Формат WebP или JPG, до 250 КБ.
- Затем в `src/courses.mjs` у курса замените `image: null` на `image: 'images/kurs-N.webp'` и запустите `npm run build`.

Пока картинки нет, на десктопе показывается цветная постерная заглушка, на мобильном блок скрыт.
