# Нейрорейтинг: топ-10 курсов по нейросетям

Статичный лендинг-рейтинг для трафика по запросам о курсах ИИ. Без фреймворков и без сервера: только HTML, картинки и шрифты.

## Загрузка на хостинг

Готовый сайт лежит в папке `site/`. Загрузите ее содержимое (не саму папку) в корень сайта на хостинге:

```
site/
  index.html        главная страница (CSS и JS встроены)
  b.html            минималистичный вариант Б для А/Б теста (см. ниже)
  privacy.html      политика обработки персональных данных
  consent.html      согласие на использование cookie
  images/           логотипы школ, WebP
  fonts/            шрифты Dela Gothic One и Onest, только нужные символы
  robots.txt
  .htaccess         сжатие и кэш для Apache (скрытый файл, загрузите его тоже)
```

После загрузки откройте сайт по HTTPS и проверьте: баннер cookie, кнопки курсов, ссылки в подвале.

## Страница Б: рейтинг по направлениям (`b.html`)

Первый экран и блок «Как мы ставили оценки» как на главной (вместо «Топ-10» — «Рейтинг», свой текст под заголовком, на широких экранах справа анимированная диаграмма рейтинга с печатью), затем «Рейтинг курсов» с цветными плитками направлений и сетка компактных карточек в едином оранжевом акценте, ниже FAQ и финальный блок. Таблицы сравнения на этой странице нет.

Клик по плитке оставляет курсы этого направления и нумерует их с 1. Адрес при этом меняется, и по такой ссылке страница сразу открывается на нужном направлении и прокручивается к списку — ее можно ставить в рекламу:

```
https://cursai.ru/b.html                 все курсы
https://cursai.ru/b.html?dir=self        Для себя
https://cursai.ru/b.html?dir=work        Для работы
https://cursai.ru/b.html?dir=marketing   Маркетинг
https://cursai.ru/b.html?dir=business    Бизнес
https://cursai.ru/b.html?dir=agents      ИИ-агенты
https://cursai.ru/b.html?dir=career      Новая профессия
```

UTM-метки можно добавлять как обычно: `b.html?dir=marketing&utm_source=yandex`. Направления берутся из `filters` в `src/courses.mjs`, курс попадает в направление по своим `tags`.

Метрика: клики по кнопкам курсов на этой странице отправляют свою цель `rating_course_click` (на главной — `course_click`), чтобы конверсии страниц не смешивались. У цели есть параметры `place`, `school` и `direction` — видно, из какого направления был переход в школу. Клик по плитке направления отправляет цель `direction_click`. Все три цели создаются в Метрике как «JavaScript-событие» с этими идентификаторами.

Страница закрыта от индексации (`noindex`) и не включена в `sitemap.xml`, чтобы не спорить с главной в поиске. Партнерские ссылки у нее свои (`affiliateB`), поэтому продажи с двух страниц можно сравнивать.

Правки текста и порядка курсов вносятся там же, в `src/courses.mjs`, — страница собирается автоматически при `npm run build`, отдельно ничего поддерживать не нужно.

## Как править

1. Тексты, ссылки, оценки, фильтры и частые вопросы лежат в `src/courses.mjs`. Итоговый балл считается из четырех критериев с весами, порядок в массиве равен месту в рейтинге. Сборка остановится, если оценки идут не по убыванию или в текстах есть буква «е» с точками.
2. Ссылка на курс внутри ответа в частых вопросах пишется так: `[текст](#kurs-4)`.
3. Стили в `src/styles.css`, поведение в `src/app.js`, разметка и настройки сайта в `scripts/build.mjs`.
4. Соберите сайт (нужен Node.js 18+):

```bash
npm run build     # site/ — папка для хостинга
npm run preview   # dist/ — превью для просмотра
```

## Настройки в `scripts/build.mjs`

- `SITE.url` / `SITE.domain` — адрес и домен сайта (сейчас `https://cursai.ru/`). Без них на странице нет canonical, og:url и sitemap.xml.
- `SITE.ymId` — счетчик Яндекс Метрики (сейчас 113107145).
- `SITE.operator.email` — почта для обращений по политике конфиденциальности (сейчас gvrsoon@yandex.ru). `SITE.operator.name`/`inn` можно заполнить, если есть ИП или юрлицо — иначе в текстах используется формулировка «владелец сайта cursai.ru».

Сборка печатает предупреждения, если что-то из этого или сроки и цены курсов не заполнены.

## Яндекс Метрика

- Счетчик подключен с параметрами из кода Метрики: Вебвизор, карта кликов, электронная коммерция (`dataLayer`), точный показатель отказов, внешние ссылки.
- Метрика запускается сразу при заходе на сайт. Уведомление о cookie внизу экрана только информирует и дает отказаться на этом устройстве — тогда при следующих визитах Метрика не грузится. Это решение (собирать данные сразу, без блокирующего согласия) сознательно выбрано вместо предварительного opt-in.
- Клик по любой кнопке курса отправляет цель `course_click`. Создайте в Метрике цель типа «JavaScript-событие» с идентификатором `course_click`, чтобы видеть переходы на сайты школ и использовать их в Директе.

## Скорость

- Шрифты лежат на своем хостинге, подмножества только с используемыми символами: около 46 КБ вместо цепочки запросов к Google Fonts.
- CSS встроен в страницу и сжат, лишние пробелы в HTML убраны. Главная страница весит около 25 КБ в gzip.
- Логотипы в WebP с заданными размерами, загружаются лениво.
- На телефонах отключены размытие под шапкой и постоянная анимация фигур, чтобы прокрутка была плавной.
- Lighthouse, мобильный режим: скорость 99, доступность 97, практики 100, SEO 100; LCP 1,7 с, CLS 0.

Если добавите текст с новыми символами (например, другой алфавит), обновите подмножества шрифтов: скачайте их с Google Fonts с параметром `text=` и замените файлы в `src/fonts/`.

## Картинки, сроки и цены

- Картинки курсов: см. `images/README.md`.
- Сроки (`duration`), формат занятий (`schedule`) и цены (`price`, в рублях) заполняются в `src/courses.mjs`. Если значение `null`, поле не показывается.

## Cookie и персональные данные (152-ФЗ)

- `privacy.html` — политика конфиденциальности (сайт не собирает персональные данные напрямую — нет форм и регистрации, только техническая статистика Яндекс Метрики), `consent.html` — отдельный текст согласия на cookie.
- Баннер показывается при первом визите, выбор можно изменить ссылкой «Настройки cookie» в подвале.
- Перед запуском подайте в Роскомнадзор уведомление об обработке персональных данных и покажите тексты юристу: это шаблон, а не юридическое заключение.

## Перед запуском трафика

- Замените ссылки курсов на партнерские и заполните `SITE.url`.
- Добавьте маркировку рекламы (erid) по требованиям закона о рекламе, если ссылки партнерские.
- Сверьте факты о программах с сайтами школ: программы и условия меняются.
