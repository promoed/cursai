# Нейрорейтинг: топ-10 курсов по нейросетям

Статичный лендинг-рейтинг для трафика по запросам о курсах ИИ. Без фреймворков: один `index.html`, `styles.css` и встроенный скрипт.

## Как править

1. Тексты, ссылки, оценки и фильтры лежат в `src/courses.mjs`. Итоговый балл считается из четырех критериев с весами, порядок в массиве равен месту в рейтинге (сборка упадет, если оценки идут не по убыванию или в текстах есть буква «е» с точками).
2. Стили в `src/styles.css`, поведение в `src/app.js`, разметка в `scripts/build.mjs`.
3. Соберите страницу:

```bash
npm run build     # index.html + styles.css
npm run preview   # dist/preview.html, все в одном файле
```

## Картинки, сроки и цены

- Картинки курсов: см. `images/README.md`.
- Сроки (`duration`), формат занятий (`schedule`) и цены (`price`, в рублях) заполняются в `src/courses.mjs`. Если значение `null`, поле не показывается, а `npm run build` выводит список незаполненных полей.

## Cookie и персональные данные (152-ФЗ)

- `privacy.html` — политика обработки персональных данных, `consent.html` — отдельное согласие на обработку (с 1 сентября 2025 года согласие должно быть отдельным документом).
- Баннер cookie показывается при первом визите. Яндекс Метрика загружается только после «Принять все». Выбор можно изменить ссылкой «Настройки cookie» в подвале.
- Номер счетчика Метрики задается в `SITE.ymId`, реквизиты оператора — в `SITE.operator` (`scripts/build.mjs`). Пока реквизиты не заполнены, сборка предупреждает.
- Перед запуском подайте в Роскомнадзор уведомление об обработке персональных данных и покажите тексты юристу: это шаблон, а не юридическое заключение.

## Перед запуском трафика

- Замените ссылки курсов на партнерские и `SITE.url` в `scripts/build.mjs` на адрес сайта (canonical).
- Добавьте маркировку рекламы (erid) по требованиям закона о рекламе, если ссылки партнерские.
- Укажите `SITE.ymId`: после согласия на cookie клики по курсам уходят в Метрику целью `course_click`.
- Сверьте факты о программах с сайтами школ: программы и условия меняются.
